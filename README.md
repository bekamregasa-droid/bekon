# Bekon – Career Discovery App

Bekon is a mobile app I built to help students figure out career paths that actually fit how they think. Instead of long, boring text surveys, it uses short interactive games to measure cognitive strengths and match users with careers that suit their natural abilities.

---

##  Built With

* **Framework:** Flutter & Dart
* **Backend:** Firebase (Auth & Firestore)
* **Design:** Custom animations and mobile-first UI

---

##  Key Features

* **6 Brain Assessment Games:** Quick minigames that test memory, pattern recognition, and problem-solving speed.
* **Smart Career Matching:** Recommends specific career paths based on performance data.
* **Visual Analytics:** Easy-to-read breakdowns of strengths and areas for growth.
* **Progress Tracking:** Saves assessment history over time to track improvement.

---

##  Core App Flow

1. **Onboarding & Auth:** Smooth intro screens with secure sign-up/login.
2. **Assessment Suite:** Interactive games to measure cognitive skills.
3. **Results & Dashboard:** Clear visualizations showing core strengths and career matches.
4. **Career Explorer:** Deep dives into recommended job roles and industries.
